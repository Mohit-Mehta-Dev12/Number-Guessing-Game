markdown# 🎯 Glassmorphic Number Guesser

A beautiful, responsive web-based number guessing game featuring a modern **Glassmorphism** user interface, interactive visual animations, and clean state logic.

## 🚀 Live Demo
▶️ [Click here to play the game live!](YOUR_GITHUB_PAGES_LINK_HERE)

## ✨ Features
* **Frosted Glass UI**: Clean glassmorphism container using backdrop-filter blur effects.
* **Ambient Glow**: Dynamic radial background gradient lighting setup.
* **Input Validation**: Strict whole integer filtering preventing decimal submission exploits.
* **Smart Game Loop**: Automatic win/loss condition evaluation with seamless restart switches.

## 🛠️ Built With
* **HTML5** - Semantic layout structure
* **CSS3** - Glassmorphism, animations, and responsive flexbox alignment
* **JavaScript (ES6+)** - Dynamic DOM manipulation and random state calculation

## 🎮 How to Play
1. The game automatically generates a hidden random integer between **1 and 100**.
2. You have exactly **10 attempts** to find the correct number.
3. Type your guess in the center box and click **Submit Guess**.
4. The system will guide you by announcing if your guess is **Too High** 📈 or **Too Low** 📉.
5. If you fail to find the number within 10 tries, it is game over! Click **Start New Game** to reset.
